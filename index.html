Help & Support

Frequently Asked Questions

What is the configured application fee?

The standard PAN facilitation fee is configured at ₹157. This covers application filing, document inspection, laminated physical card dispatch by India Post, and digital e-PAN delivery.

What documents are required for PAN application?

You need three proofs: Proof of Identity (Aadhaar, Passport, Voter ID), Proof of Address (Aadhaar, Utility Bill, Bank statement), Proof of Date of Birth (Aadhaar, Birth Certificate, 10th marksheet), plus 1 passport size photograph and signature.

What happens if my document is rejected?

If a document is unclear or invalid, our admin marks it with a specific reason. You will receive an immediate notification and can re-upload a clearer copy from "My Documents" without paying any extra fee.

Is this the official Income Tax portal?

No. This portal is a facilitation and demo platform. It does not falsely represent itself as the Income Tax Department, UTIITSL, or Protean. When running in Sandbox mode, applications are simulated for processing.

Sketchware & HopWeb APK Build Guide

Convert this Web App into a Native Android APK
1
Create New Sketchware Pro Project

Open Sketchware, tap (+) to create a new project. Name it PAN Card Apply and set Package Name (e.g. com.digitaldhadi.pancard).

2
Add WebView Component

Drag a WebView component from the palette onto main.xml. Set width and height to match_parent.

3
Enable Android Permissions in AndroidManifest

In Sketchware's Permission Manager, check the following permissions:

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
4
Add Java Logic in onCreate Event

In MainActivity.java → onCreate, add this block to support file uploads and modern web standards:

webview1.getSettings().setJavaScriptEnabled(true);
webview1.getSettings().setDomStorageEnabled(true);
webview1.getSettings().setAllowFileAccess(true);
webview1.getSettings().setAllowContentAccess(true);
webview1.setWebChromeClient(new WebChromeClient());
webview1.loadUrl(getCurrentAppUrl());
5
Run & Build APK

Tap RUN in Sketchware to compile the project into a signed Android APK file ready to install on your phone!

1
Open HopWeb App

2
Load Direct App URL or Local Bundle

3
Export as APK

Go to Project Settings → Export → Build Signed APK.

Install Immediately on Android without Sketchware

You don't need any complex compiler. This portal is a Progressive Web App (PWA):

  1. Open this URL in Google Chrome on your Android mobile
  2. Tap the 3 vertical dots in Chrome's top right corner
  3. Tap "Install app" or "Add to Home Screen"
  4. An app icon will appear on your Android launcher that launches full-screen like a native APK!
